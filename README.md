# UBowl 门店空间档案

根据用户提供的 8 张照片和 4 段视频还原顾客可见的 UBowl 门店。

## 查看与维护

- 静态页面在 `dist/`，运行 `python -m http.server 4173 --bind 127.0.0.1 --directory dist`。
- 模型源文件与可复现 Blender 脚本保存在相邻的 `store-model/`。
- 部署身份以 `.openai/hosting.json` 为准，复用该 Site，勿重新创建。
- 用户指定公开地址：`https://ubowl.mia-dynamic.com`。
- 模型通过 GLB 加载，支持旋转、缩放、平移、五个固定视角、隐藏顶棚、自动旋转和模型下载。
- 实拍对照保存原照片；视频仅无损重新封装为适合浏览器读取的 MP4，未生成或替换店铺画面。
- 视频不会自动播放，打开后可手动播放；参考弹窗支持键盘左右键和 Escape。
- 模型加载失败或 WebGL 不可用时，仍可浏览实拍资料和下载模型。

## 还原边界

没有现场尺寸图。宽高、进深与设备间距为照片比例估算。未完整拍摄的后厨不作为精确还原。
按用户反馈重排右侧入口、冷柜与侧壁碗筷柜，净通行宽度以用户估计的约 1 米为建模目标。该数值未经现场测量。
模型用于空间查看与沟通，不作为测绘、施工或设备定位文件。

## 第三方依赖

Three.js 0.186.1，MIT 许可；许可全文随页面保存在 `dist/vendor/THREE-LICENSE.txt`。
仅保留实际使用的官方模块，页面不依赖外部 CDN 或第三方字体服务。
参考图像、视频与品牌文字由用户提供，仅用于本次指定门店还原。
